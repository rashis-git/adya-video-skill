# Script style (Step 3)

A great video is mostly a great script. The pipeline is deterministic; the writing is where it lives or dies. Write the script first, get it approved, *then* spend on audio.

## Pacing
- ~2.5 words/second. 15s ≈ 35 words; 30s ≈ 75; 60s ≈ 150.
- The script should feel SHORTER than the runtime — leave room for visual beats and silence.

## Voice (Adya)
- Precise, confident, calm authority. "Smart engineer who's seen the failures," not a hype reel.
- Contractions, varied sentence length, short punchy lines mixed with one longer line.
- Concrete over vague: "runs marketing, sales, and support as one governed system" beats "streamlines your workflow."

## Banned words (from Rules.md) — do not use
Delve, Unlock, Unleash, Harness, Elevate, Foster, Leverage, Empower, Transformative, Groundbreaking, Cutting-edge, Supercharge, Enhance, Resonate, Journey, Embark, Navigate, Unveil, Testament, Remarkable, Unprecedented, Ever-evolving, Crucially, Expertise, Insights. Banned phrases: "This is about…", "Not only… but also…", "In the fast-paced world of…", "Revolutionize the way", "Game-changer".

## Beat structure (15s social default): hook → solution/PUNCH → proof → CTA
1. **Hook** — a tension or contrast in the first 3s. Not "Introducing X." (Good: "Go-to-market teams drown in tools and busywork.")
2. **Solution / PUNCH** — what Adya does, concretely. The centerpiece frame.
3. **Proof** — the capability/loop, or a real proof point.
4. **CTA** — "Build with Adya · adya.ai".

Longer formats: 30–60s add a Story beat and more Proof. Don't force four beats into a clip that wants two.

## Grounding Adya facts (so teammates don't need to know them)
Pull accurate specifics from the Adya knowledge base when relevant — don't invent. Reliable anchors:
- **Platform:** Vanij — full-stack enterprise agentic AI platform. **SAI** — conversational layer / primary UI.
- **Core IP:** **AGP** (Adaptive Governance Protocols), **MAN** (Multi-Agent Network), **ESM** (Event-Sourced Memory).
- **Positioning:** governance-first; the antidote to the ~40% of agentic-AI projects that fail (Gartner). "Platform, not a point solution."
- **Agents:** GTM Agent (marketing + sales + support), Recruitment Agent, ESA, etc.
- **Proof points:** 7 patent applications; NVIDIA / Google Cloud / Accenture validation; INSEAD AI50; Terminal Bench #6.
If a fact isn't confirmed, soften the claim rather than overstate it — senior viewers catch inflation instantly.
